# in-page-sense 文档中心

本目录参考 SlimVID / in-page-bot 文档三层治理习惯，按 **写权限与真源角色** 组织。库体量小，目录从简；需要时再扩展。

## 三层结构

```text
docs/
├── 人类文档/          人写，AI 只读（原始手稿；暂空）
├── AI文档/            已固化 harness（须明确指令才写；暂空占位）
└── AI与人类/          人与 AI 共同维护（进行中）
    ├── 需求拟定/      ← 当前需求真源
    ├── 规范和原则/    ← 快照诚实与失败方向
    └── 决策与复盘/    ← 源码 TS 等已裁决项
```

| 层 | 入口 | 说明 |
|----|------|------|
| 人类文档 | [`人类文档/README.md`](./人类文档/README.md) | 原始意图手稿 |
| AI 文档 | [`AI文档/README.md`](./AI文档/README.md) | 固化后的产品/工程 harness |
| AI 与人类 | [`AI与人类/README.md`](./AI与人类/README.md) | 进行中的需求、原则、决策 |

工程规则（Cursor）：[`.cursor/rules/`](../.cursor/rules/) · Agent 入口：[`../AGENTS.md`](../AGENTS.md)
