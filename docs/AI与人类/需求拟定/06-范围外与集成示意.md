# 06 — 范围外与集成示意

## 6.1 明确不做（本库）

| 类别 | 说明 |
|------|------|
| 控制 | 虚拟指针、`click`、`type`、`selector.click()` |
| 编排 / 通道 | `pageId` 信封、插件握手、WebSocket、MCP server、`escapes` |
| BOM | `reload`、`eval`、`location.assign`、任意脚本执行 |
| 宿主闸门 | `SLIMVID_APP_ENV`、`SLIMVID_E2E_ENABLED`、`isInjectE2eAttr` |
| 打点组件 | `E2ePlayable` / region 包装（`display: contents` 属于宿主 UI） |
| 业务表 | 内置 SlimVID 岛 selector；把 Polarise CSS hash 写进库 |
| 运行时依赖 | Playwright、第三方线框 IR、默认 html2canvas（截图用 modern-screenshot） |
| 推送 | MutationObserver / MCP 推全量树 |
| 操作逃生 | 允许 Agent `run(generic.ref)`（那是另一条合同，V1 不做） |

## 6.2 与姊妹库的组合关系

```text
宿主（打点 + 闸门）
  → DOM 上出现 data-e2e-*（仅会话允许时）

in-page-sense（本仓）
  → snapshot() → TSenseSnapshot
  → resolve(id) → Element | null（与菜单同一套收口）

in-page-playable（另仓，编排）
  → 信封：pageId + pageTitle + requestId
  → 调用 sense.resolve(id) 得到 Element
  → 按 code 决定是否开放 BOM

in-page-bot（另仓，控制）
  → 只接收 Element / 坐标，不读本库 DTO

in-page-bom（另仓或 playable 内模块）
  → 仅逃生；本库不调用
```

本库 **不负责** 闭环「看到什么再点下去」；只保证「按合同扫完并诚实分类」。

## 6.3 与 SlimVID 等宿主的集成示意（非本库范围）

```text
development + E2E_ENABLED + 插件握手
  → 宿主 isInjectE2eAttr = true → E2ePlayable 包装出现
  → 宿主 createSense({ root: appIframeDocument, islandSlots })
  → 编排层把 snapshot 发给插件

production / 未握手：宿主不得打点；本库若被误挂，只能扫到空点位或退化
```

本库不读取 Shopify / SlimVID 环境变量，也不实现 React 包装。

## 6.4 截图策略（已对齐）

| 方案 | V1 |
|------|-----|
| 日常 `snapshot()` 出图 | **否** |
| `snapshot({ image: true })` 整页长图 + 红框/label + `currentView` | **是**（默认 `modern-screenshot`；拍前临时关 `backdrop-filter`，拍完恢复） |
| 本库默认 html2canvas | **否** |
| 宿主注入 `captureScreenshot` 覆盖底图 | 可选；标注仍由本库；尺寸不符 → 双 `null` |
| 失败 | `screenshot` 与 `currentView` 双 `null` |
| 用截图 / 红框算 xy 再点 | **禁止** |
