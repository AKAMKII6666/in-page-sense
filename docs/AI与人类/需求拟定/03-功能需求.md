# 03 — 功能需求

## 3.1 扫描引擎（核心）

| ID | 需求 | 说明 |
|----|------|------|
| F-SCN-01 | Root 作用域 | 只扫 `createSense({ root })` 给定的 Document / ShadowRoot / Element |
| F-SCN-02 | pagetitle 现读 | 每次 `snapshot()` 读第一个非空 `data-e2e-pagetitle` |
| F-SCN-03 | 点位扫描 | 收集 `data-e2e-*`：playable / island / content / region |
| F-SCN-04 | 叶子字段 | playable 需要 id / event / title / desc（缺字段的节点不进菜单；可记入扫描诊断，不抛死宿主页——抛错属于宿主注入组件） |
| F-SCN-05 | enabled | 读内层 `button, a, input, [role=button]` 的 disabled / aria-disabled / loading，不读 contents 包装 |
| F-SCN-06 | content 文本 | `innerText` 截断；禁止 innerHTML |
| F-SCN-07 | resolve(id) | 把本帧菜单 id 解析成瞄准 Element。与 snapshot 共用扫描/收口：叶子取内层控件（没有则包装），岛合成 id 取槽位。焦点层外、空挡层、OUTSIDE_ROOT、degenerate、generic `g0`、空/未知 id → `null`。同步，不派发事件。 |

宿主未注入点位时，自主菜单可以为空（合法）；空菜单 + 有 pagetitle ≠ degenerate。

## 3.2 字符树与 stacking

| ID | 需求 | 说明 |
|----|------|------|
| F-TRE-01 | 浅树 | 只含 region、点位、content、岛展开、推断 `[row]`、stacking |
| F-TRE-02 | 塌壳 | Polarise / 匿名无合同节点连续塌掉 |
| F-TRE-03 | Portal | 树按 stacking/portal 编，不按业务父组件假挂 |
| F-TRE-04 | `[row]` | 从 `tr` / `[role=row]` 推断，无 id、不接操作 |
| F-TRE-05 | stacking 收入 | 见 `02`；无点位 stacking 无 id |
| F-TRE-06 | box 按需 | 日常 snapshot 不带 box；仅 `image: true` 时 playables 可带文档坐标 `box`（与长图同系） |

## 3.3 焦点层与 generic

| ID | 需求 | 说明 |
|----|------|------|
| F-FOC-01 | 收口 | `cover=most` → `view: "blocking-layer"`，列表+树同时收 |
| F-FOC-02 | 空层附件 | 层内 0 playable → `BLOCKED_NO_PLAYABLE` + `fallback` |
| F-GEN-01 | generic 扁列表 | `interactables[]` 有配额；临时 `ref` 不可当作 e2e id |
| F-GEN-02 | a11yText | 浅字符/YAML，有截断 |
| F-GEN-03 | screenshot（legacy 字段） | `generic`/`fallback.screenshot` 仅在 `image: true` 成功时与顶层同步；日常为 `null` |
| F-IMG-01 | 按需诊断图 | `snapshot({ image: true })` 才拍；整页 CSS px；红框+label；顶层 `screenshot`+`currentView` 同有同无 |
| F-IMG-02 | 覆盖底图 | 可选 `captureScreenshot` 只换底图；sense 仍统一标注；尺寸不符 → 双 `null` |
| F-DEG-01 | 无 pagetitle | 整份 `mode: "degenerate"`，顶层 `generic` + 投影 `playables` |

## 3.4 岛展开

| ID | 需求 | 说明 |
|----|------|------|
| F-ISL-01 | 宿主表 | `createSense({ islandSlots })` 按 island `id` 索引槽位 |
| F-ISL-02 | 寻址 | `aria-label` / `role` + 可见名；禁止 Polarise CSS hash |
| F-ISL-03 | Tabs Measurer | 排除 `id` 以 `Measurer` 结尾的测量节点 |
| F-ISL-04 | 合成 id | 如 `list-pagination:next` 写入 `playables` 与树 |
| F-ISL-05 | 找不到 | 该槽位不进列表；不得静默当成已点 |

无 `islandSlots` 时：岛只在树上作为 `island` 节点出现，不展开合成 playable。

## 3.5 配额（V1 建议默认，可配置）

| 项 | 默认 |
|----|------|
| generic `maxNodes` | 80 |
| content `text` | 200 字 |
| `a11yText` | 4000 字 |
| `asciiTree` | 实现可再截断并标明 truncated（若加字段须写进 `04`） |

超出则截断 + `truncated: true`（generic）；不得为「完整」拉爆调用方上下文。

## 3.6 库形态

| ID | 需求 | 说明 |
|----|------|------|
| F-PKG-01 | 独立 npm | ESM + TypeScript 类型 |
| F-PKG-02 | 运行时依赖 | 允许 `modern-screenshot`；不依赖 React / Playwright / html2canvas |
| F-PKG-03 | 单一入口 | `createSense(options)` → `{ snapshot, resolve }` |
| F-PKG-04 | 无控制 API | 不提供 click / eval / reload / postMessage |
