# 05 — 工程结构与分期

## 5.1 推荐目录

```text
in-page-sense/
  package.json
  README.md
  docs/                          # 本文档树
  src/
    index.ts                     # createSense 入口（唯一公开 barrel）
    types.ts                     # TSenseSnapshot 等
    sense.ts                     # 门面：分流 → scan / tree / generic
    scan/                        # pagetitle、点位、enabled、content 文本；岛展开先放这里
    tree/                        # ascii 树、stacking、焦点层收口、[row]
    generic/                     # 退化 / BLOCKED_NO_PLAYABLE 附件
  playground/                    # 本地 HTML 验收（不进主产物）
  tests/                         # vitest；DTO 判别与 id 同一套契约
```

建议：打包 ESM + `.d.ts`；运行时 **零依赖**；不 peer 强制 React。

`scan/` / `tree/` / `generic/` 从第一份实现起就按职责分目录，避免根上平铺扫描器、编树器、退化器。

## 5.1.1 语言与产物（已裁决）

产物为标准 ESM + `.d.ts`，JS/TS 宿主均可消费。

裁决全文与理由见：[`../决策与复盘/源码TypeScript与产物形态.md`](../决策与复盘/源码TypeScript与产物形态.md)。

## 5.2 感知数据流

```text
snapshot() / resolve(id)
  → 现读 pageTitle
  → 无 / 空 → snapshot: degenerate；resolve: null
  → 有 → 扫点位 + stacking
  → 若 cover=most → 收口为 blocking-layer
  → snapshot: 若层内 0 playable → 附 generic @ blocking-layer → TSenseSnapshot
  → resolve: 在收口后的 playables 里找 id；命中则瞄准内层控件，否则 null
```

不在 `snapshot()` / `resolve()` 里 `dispatchEvent`、不写 DOM 点位、不握手。`resolve` 与 `snapshot` 必须走同一套 live menu，禁止两份扫描名单。

## 5.3 分期

**节奏约定：** 合同已写入 `02`–`04`，但 **按下列顺序编码，不提前合做打乱节奏。**

| 阶段 | 交付 | 验收 |
|------|------|------|
| **P0** | pagetitle 分流；自主 `playables` + `contents` + 浅 `asciiTree`（`view: "page"`）；degenerate 可先只出空 generic 壳 | playground 有 pagetitle 时出菜单；无则 mode=degenerate |
| **P1** | stacking 收入 + `cover` + 焦点层收口（列表和树一起） | 全屏遮罩下只见层内 id |
| **P2** | `BLOCKED_NO_PLAYABLE` + generic a11yText / interactables；`captureScreenshot` 可选（允许 null） | 空挡层附 fallback；ref 不进 playables |
| **P3** | island 展开 + Measurer 排除 + 契约测试 + npm 可发布骨架 | 合成 id 与树一致；typecheck / test 过门禁 |
| **0.1.1** | `resolve(id)`：与 snapshot 共用 live menu，把菜单 id 解析成瞄准 Element | 包装→内层控件；层外 / 空挡层 / `g0` → `null` |

playground 建议：一页带 `data-e2e-pagetitle`、若干 playable / content / 假 Modal 挡层；一页无 pagetitle。不必 P0 一次做满 Polarise 复刻。
