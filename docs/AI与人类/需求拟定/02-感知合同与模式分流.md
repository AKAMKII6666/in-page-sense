# 02 — 感知合同与模式分流

本库没有「老 `_bot` 行为」要对齐。本文件是感知真源：**何时走自主合同、何时退化、挡层如何收口。**

## 2.1 页身份：每次现读

隐藏节点（一个 `root` 最多认第一个）：

```html
<div hidden data-e2e-pagetitle="dashboard-ready-list"></div>
```

| 探测 | `mode` |
|------|--------|
| 找到 `data-e2e-pagetitle` 且值非空 | **`autonomous`**：扫 `data-e2e-*` |
| 没有 / 值为空 | **`degenerate`**：普通快照 |

**不要**用 `document.title` 凑。同一 iframe 内路由切换后必须重新读，禁止在 `createSense()` 时冻住 `pageTitle`。

`pageId` **不属于**本库（编排层生成）。本库回包装 `pageTitle: string | null`。

## 2.2 点位 kind（宿主打点，本库扫描）

| `data-e2e-kind` | 作用 | 进 `playables` |
|-----------------|------|----------------|
| `playable` | 叶子可操作 | 是 |
| `island` | Polarise 等包不住的复合体 | 否（展开 slot 后进列表） |
| `content` | 只读文本 | 否（进 `contents`） |
| `region` | 业务块 | 否（只进树） |

未写 `kind`、带 `data-e2e-event` 的视为 `playable`。

推断结构（不打点）：现成的 `tr` / `[role=row]` 可收成匿名 `[row]`，只为箍同行。本库不要求宿主包装 `tr`。

叶子瞄准几何 **不是**本库的执行合同（那是 bot）。本库只报告 id 与树；包装常为 `display: contents`，无盒子。

## 2.3 自主快照：两份、同一套 id

- **`playables[]` + `contents[]`：** 操作真源。Agent 点这里的 `id`。  
- **`asciiTree`：** 认路；Polarise 匿名壳塌掉；关键节点带同一 `id`。  
- **不要**第三份深 DOM JSON 当真源。

树按 DOM + Portal/stacking 编，不要按业务父组件假挂（Modal / Popover 常 portal 到 body）。

## 2.4 stacking 与 `cover`

收入（不要 `position !== static` 全收）：

| 收入 | 不收入 |
|------|--------|
| `fixed` / `sticky` / `absolute` | 纯 `relative` 且 `z-index: auto` |
| `relative` **仅当** `z-index` 为数字 | `display:none`、零尺寸、不可见 |
| | 无 e2e 子孙且 `cover=corner` 的小层（Tooltip 等）默认省略 |

字段：`position`、`zIndex`（计算值）、`cover`（`most` / `partial` / `corner`）、可选 `w×h`。**默认不给 `x,y`。**

`cover` 在库内用视口相交面积分档。V1 建议：相交 ≥ 50% 视口 → `most`。精确矩形仅 debug 通道，不进默认 Agent 快照。

开关是 **挡住视口**，不是 z-index 数字最大。

## 2.5 焦点层（`view: "blocking-layer"`）

存在 `cover=most` 且会拦住指针的 stacking 时：

- **列表和树一起收**到该层子树。  
- `blocking` 必填；`playableCount` 为该层（含岛展开）数量。  
- 同屏多块 `cover=most`：取最靠上、会拦住指针的那块。  
- `cover=partial` / `corner`：不收口（partial 时抽屉 region 可在树里置顶，仍出全页列表）。

## 2.6 空挡层 → 感知逃生（同一次 snapshot）

`cover=most` 且层内 **零 playable、零可展开岛槽位**：

- `code: "BLOCKED_NO_PLAYABLE"`
- `playables: []`、`contents: []`
- `fallback` 为 generic（浅 a11y + 可选截图）；`scope: "blocking-layer"`
- **禁止**把 `fallback.interactables` 写入 `playables`

iframe 外挡层（如 Admin chrome）本库在 `root` 内可能看不见：能判定时用 `BLOCKED_OUTSIDE_ROOT`；不能判定则只报本 `root` 所见。编排层据此决定 BOM，**本库不回 `escapes`**。

## 2.7 感知是拉

只响应调用方的 `snapshot()` / `resolve(id)`。不 MutationObserver 推树，不向 MCP 推全量。调用间隔由编排/Agent 决定。`resolve` 与 `snapshot` 共用扫描/收口，不另开名单。
